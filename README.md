## 🛠️ Pokretanje
1. Instalacija biblioteka: `pip install -r requirements.txt`
2. Importovati SQL fajl u phpMyAdmin.
3. Pokrenuti server: `python app.py`

## 📋 Karakteristike
- Login i Registracija
- Nasumična pitanja (10 po kvizu)
- Tajmer od 90 sekundi
- Rang lista najboljih rezultata
